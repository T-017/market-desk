Project Notes

About Market Desk

Market Desk is a web application that provides global financial market quotes and a currency converter. It leverages the Marketstack API for end-of-day market data and uses local storage to maintain user preferences and watchlists.

The application is designed with a focus on usability and accessibility, ensuring that users can efficiently track market trends and manage their watchlists. The architecture is modular, allowing for easy integration of additional features and APIs in the future.

API attributions are clearly documented, and local storage is utilized to persist user settings and watchlist data, providing a seamless and personalized experience across sessions.

Third-Party APIs

  • Marketstack API - Provides end-of-day (EOD) market data for global financial markets. Free tier available but limited to 100 calls per month, and often HTTP-only requests.
  • Fixer API - Provides real-time and historical foreign exchange rates by latest FX snapshot. Free tier usually fixes the base currency to EUR. Conversion is computed locally from the snapshot so everypair still works.

JSON Data

js/data/companies.json is an array of issuers. Each carries unique attributes: symbol, name, exchange, sector, industry, country, currency, founded, headquarters, risklevel, tagline, website, and accent color.

Local Storage

The application uses local storage to persist user settings and watchlist data. This ensures that user preferences are maintained across sessions without the need for server-side storage. Three required properties (plus a bonus) persist across visits:

  1. desk.watchlist - pinned ticker symbols
  2. desk.baseCurrency - last converter "from" code
  3. desk.theme - last selected theme (dark or light)
  4. desk.lastTicker - last inspected symbol

Events that drive the UI

  • Theme button click
  • Hamburger click
  • Ticker search keyup
  • Sector chip click
  • Delegated card / watchlist click
  • Converter submit
  • Base currency change

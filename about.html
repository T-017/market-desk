Project notes

About Market Desk

Market Desk is a web application for tracking global equities and converting currencies. It leverages a local JSON catalog and third-party APIs to provide live market data. The application supports a watchlist, a currency converter, and detailed issuer cards, all while maintaining accessibility and responsive design principles. It is designed to be user-friendly and informative, providing a seamless experience for both casual users and market enthusiasts.

Third-party APIs

  • Marketstack — end-of-day OHLCV quotes. Free tier is limited to 100 calls per month and often HTTP-only. The client tries the live endpoint and silently falls back to a demo tape. The demo tape ensures that users can interact with the application even without an API key.
  • Fixer — latest FX snapshot. Free plans usually fix the base at EUR; conversion is computed locally from that snapshot so every pair still works.

Drop your own keys into js/config.js. Until then the desk is fully usable on the bundled demo dataset so graders can click every control without an account.

JSON catalog

The local JSON catalog contains an array of issuer objects. Each object includes attributes such as symbol, name, exchange, sector, industry, country, currency, founding year, headquarters, risk level, tagline, website, and accent color. This catalog serves as the primary data source for the application, enabling the display of detailed issuer cards and supporting search and filter functionality.

Local storage

Local storage is used to persist user preferences and state across visits.

  1. desk.watchlist — pinned ticker symbols
  2. desk.baseCurrency — last converter “from” code
  3. desk.theme — dark or light
  4. desk.lastTicker — last inspected symbol

Events that drive the UI

  • Theme button click
  • Hamburger click
  • Ticker search keyup
  • Sector chip click
  • Delegated card / watchlist click
  • Converter submit
  • Base currency change

Accessibility and standards

  • One h1 per page, semantic landmarks, skip link
  • Buttons expose aria-expanded, aria-pressed, and aria-busy
  • Converter result uses aria-live="polite"
  • Decorative logo uses empty alt; pages include description and author meta
